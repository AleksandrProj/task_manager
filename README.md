# Task Manager

Веб-приложение для совместного управления задачами. Пользователи могут создавать
задачи, назначать исполнителей, отслеживать статус и обсуждать работу в
комментариях.

## Возможности

- Вход по JWT и защищённые страницы.
- Создание, просмотр, редактирование и удаление задач.
- Разные права для создателя и исполнителя задачи.
- Комментарии к задачам и серверная пагинация.
- Адаптивный интерфейс для компьютеров и телефонов.

## Стек

- **Backend:** Python, Django, Django REST Framework, PostgreSQL, JWT.
- **Frontend:** React, Vite, React Router, CSS Modules.
